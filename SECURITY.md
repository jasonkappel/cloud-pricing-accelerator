# Security

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report them privately through GitHub: open the repository's **Security** tab and select **Report a
vulnerability**. Include as much of the following as you can:

- the type of issue (for example, authorization bypass, injection, or information disclosure),
- the affected files, endpoints, or configuration,
- steps to reproduce, and a proof of concept if you have one,
- the impact you expect.

This repository is sample code under the MIT License, not a supported product. There is no service-level
commitment for fixes. If you deploy it, you own the deployment: review [docs/PREREQUISITES.md](docs/PREREQUISITES.md)
and the [Demo vs production](README.md#demo-vs-production) notes, and apply your organization's security
review before any production use.
